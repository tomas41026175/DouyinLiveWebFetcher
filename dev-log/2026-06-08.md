## admin 上傳體驗 + 背景自動 hot reload
- **上傳進度 + 成功狀態**：`admin.html` 加進度條（`#progWrap/#progBar/#progTxt`），上傳時即時顯示「done/total ✓ok ✗fail」+ 填充寬度；完成後 `say` 總結、進度條延遲隱藏（成功 1.5s / 有失敗 4s）。
- **多選數量上限**：`MAX_BATCH=20`，超過時 onchange/uploadFiles 擋下提示分批；hint 文字同步。要改數量改 `MAX_BATCH`。
- **背景輪詢 + hot reload**：`server.js pollGitUpdate`（`STICKER_GIT_POLL=1` 啟用，start_all.sh/.bat 都設）每 60s（`STICKER_GIT_POLL_MS` 可調）`git fetch` 比對 HEAD vs `@{u}`；remote 較新 → `pull --ff-only`；變更含 `chatroom/stickers/` → `broadcastStickerList()` 熱刷新前端面板（免重整免重啟），純 code 變更則 log 提示需重啟。`gitPolling` flag 防重疊、`unref` 不阻 exit、失敗靜默。
  - ⚠️ 依賴當前分支有 upstream（生產跑 main 有 origin/main）；無 upstream 分支 `rev-parse @{u}` throw 被 catch 靜默。
  - 設計：Windows 同時 push(git-sync)+pull(poll)；Mac 只 poll（不設 `STICKER_GIT_SYNC`）拉 Windows 的貼圖。

## 貼圖入 GitHub + 變更後自動同步 + 暫停 VPS CI
- **暫停 VPS CI**：`deploy.yml` 的 `on.push` 觸發整段註解掉，只留 `workflow_dispatch`（手動）。原因：VPS 暫停 + 避免貼圖自動 push 一直觸發部署。恢復 VPS 時取消註解即可。
- **貼圖入 git**：`chatroom/.gitignore` 移除 `stickers/*` 排除、加 `!stickers/*.png` 蓋過全域 `*.png`。webp/png/gif/jpg 都可進 git（已驗證 `??` 納入追蹤、`check-ignore` 無輸出）。⚠️ 與原設計「圖不進 git」相反，刻意改。
- **自動同步**：`server.js` 新增 git-sync — env `STICKER_GIT_SYNC=1` 才啟用（`start_all.bat` 已設，Mac/VPS 預設不觸發）。`handleUpload`/`handleDelete` 成功後 `scheduleGitSync()` → debounce 5s（`STICKER_GIT_SYNC_MS` 可調）合併連續變更 → `git add chatroom/stickers` →（`diff --cached --quiet` 無變更跳過）→ `commit` → `push`。用 `execFile('git',...)` 跨平台無 injection、cwd=REPO_ROOT；失敗只 `console.warn` 不阻斷上傳。
- **前提/限制**：① 只在跑 server 的那台（Windows）git credential 有**寫入權限**才 push 得出去（autoUpdate 只用 read，push 需確認）；② `runGitSync` 無 `pull --rebase`，若 remote 先有新 commit 會 non-fast-forward push 失敗（log 警告，單台為主場景 OK）；③ commit+push 實際行為未本機實測（避免污染 repo），待 Windows 實機驗證。
