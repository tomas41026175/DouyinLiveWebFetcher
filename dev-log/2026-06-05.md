- 鐵證：`git diff cc11e42 00b13cc -- start_all.sh` 隧道建立/抓網址邏輯（line 102/106）逐字相同 → **非本次 merge 造成**

### 決策
- 先 rollback main（revert 3 個 commit），在 `fix/china-access` 處理（從 00b13cc 重建 + revert-the-reverts 恢復功能，避免 revert 陷阱）
- 方案評估：trycloudflare/ngrok（中國封）、cpolar/natapp（要大陸實名，台灣人辦不了）、Cloudflare named tunnel（IP 仍被封）
