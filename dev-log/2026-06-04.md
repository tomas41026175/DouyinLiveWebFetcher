## chatroom 六項功能（branch: feat/chatroom-features）

spec: `docs/specs/2026-06-04-chatroom-features-design.md`

### #1 start_all.sh 自動開公網聊天室分頁
- 問題：原 `open ... >/dev/null 2>&1 || true` 吞掉所有輸出，無法得知為何聊天室分頁沒開（實測只開了 webUI）
- 修正：重構結尾——明確算出 `CHAT_OPEN_URL`（公網優先 fallback localhost）、印出 URL、`open` 失敗給回饋與手動網址、兩分頁間 `sleep 1`
- 決策：開公網網址（非 localhost），讓 #2 QR 用 `location.origin` 天然正確

### #2 分享鈕 + QR modal
- topbar 加「分享」鈕 → modal（QR + 網址 + 複製 + 關閉 + ESC/遮罩關閉）
- QR 編碼 `location.origin`（自動是公網）
- vendored `kazuhikoarase/qrcode-generator@1.4.4`（MIT, 無依賴）到 `public/vendor/`，不走 CDN（中國可用）
- `makeQR` 自動遞增 typeNumber 以容納長網址

### #3 彈幕分類 chips 過濾
- 彈幕區頂部加 5 chips（聊天/禮物/進場/關注/讚），預設全開 + localStorage 記憶
- `display:none`(dhidden) 保留 DOM 可即時切換，切換時重掃現有行

### #4 貼圖功能
- `chatroom/stickers/` 資料夾（圖片不進 git）
- server.js：圖片 MIME + `GET /stickers`(natural sort) + `/stickers/*` 靜態(白名單+穿越防護) + ws `sticker` 廣播(白名單驗證) + 鏡像 webUI
- index.html：composer 貼圖鈕 + grid 面板 + 圖片氣泡
- web_danmaku.py：`/chat/ingest` 收 `sticker_url`（限 `127.0.0.1` 前綴）+ webUI 渲染 `<img>`（DOM 設 src 防注入）

### #5 貼圖批次重命名工具
- `chatroom/scripts/rename-stickers.mjs` + `npm run stickers:rename`
- 按 mtime → `001.<ext>`（保留副檔名轉小寫、補零 3 位）、兩階段防碰撞、冪等
